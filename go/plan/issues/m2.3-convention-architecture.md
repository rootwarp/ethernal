## Issue M2.3-1 — `internal/network` single registry table

- **Points:** 3
- **Priority:** P2
- **Closes:** FR-P2-A3 (GO-047)
- **Depends on:** —

**Description.** Per architecture §6.1: derive every per-network metadata access from a single package-level `map[Network]Params` (`paramsByName`) initialised at `init()` time. Remove the four-site duplication (`Lookup`, `LookupByChainID`, `ParseFlag`, mustParseAddr-on-call). A typo'd address must panic at process start, not at first `Lookup`.

**Implementation notes.**
- File: `internal/network/network.go:57-62`, `:64-154`.

- Address parsing happens once at `init()`.

**Acceptance criteria.**
- [ ] `paramsByName` is the single source.
- [ ] `TestNetworkInit_BadAddressTypo_PanicsAtInit` (using `recover()` in a sub-process or init-time test).
- [ ] Existing network lookup tests green.
