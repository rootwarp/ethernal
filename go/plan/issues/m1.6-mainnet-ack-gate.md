**Objective.** Close FR-P1-A — the headline v1.0 user-visible safeguard. After this phase, an operator cannot accidentally broadcast a mainnet deposit.

**Dependencies.** M0.11, M1.5 (`ConfirmReader` for the prompt; `TestExitCodeContract` gates).

**Exit criteria recap (project-plan §M1.6).**
- Integration test: `--yes --network mainnet` without `--confirm-network=mainnet` → exit 2.
- Integration test: `--confirm-network=hoodi` on mainnet-shaped chainID RPC → exit 2.
- Integration test: `--signer local --network mainnet` without `--i-accept-local-signer-on-mainnet` → exit 2.
- Test matrix (FR-P1-A2) all green.

## Issue M1.6-1 — `--confirm-network=<name>` flag implementation

- **Points:** 3
- **Priority:** P1
- **Closes:** FR-P1-A1 (GO-013) — flag
- **Depends on:** M1.5-1 (pre-validate pattern), M1.5-4 (ConfirmReader)

**Description.** Per architecture §6.12 / §7.3: new flag `--confirm-network=<name>` on `eth-deposit-tx` `send`/`run`/`build` (build for symmetry). Value must equal the decoded-RLP network name AND the RPC-derived network name (where RPC available). `--yes` does NOT bypass.

**Implementation notes.**
- File: `cmd/eth-deposit-tx/{run,sign,send,main,config}.go`.
- Pre-validated in `Load*Config` (per M1.5-1 pattern).
- The value comparison happens in `sendAction` after `validateSignedAgainstRLP` returns the decoded tx (so we have the RLP network name) and after the RPC chainID guard returns the RPC-derived name.
- Mainnet network: when `--network mainnet` is selected, `--confirm-network` is REQUIRED; otherwise it's optional but if set must match.

**Acceptance criteria.**
- [x] `TestSend_MainnetWithYesButNoConfirm_Reject`: `--yes --network mainnet` without `--confirm-network=mainnet` → exit 2.
- [x] `TestSend_ConfirmNetworkMismatchRPC_Reject`: `--confirm-network=hoodi` on mainnet-shaped RPC → exit 2.
- [x] `TestSend_ConfirmNetworkMatch_Allow`: all three sources agree → no rejection.
- [x] Flag visible in `--help`.

## Issue M1.6-2 — `--i-accept-local-signer-on-mainnet` flag

- **Points:** 2
- **Priority:** P1

**Implementation notes.**
- Files: `cmd/eth-deposit-tx/{run,sign,send,config}.go`.
- Warning text per PRD §9 / UX notes: describe the risk of local key on mainnet; require explicit opt-in.

**Acceptance criteria.**
- [x] `TestSend_LocalSignerMainnet_NoAcceptFlag_Reject` → exit 2.
- [x] `TestSend_LocalSignerMainnet_WithAcceptFlag_Allow` → warning logged, proceeds.
- [x] Ledger signer on mainnet does NOT require the flag (unchanged).
