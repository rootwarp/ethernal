# Phase M0.7 — Silent-Loss & Data-Correctness Bulk

**Objective.** Close the FR-P0-B medium/low cluster — every silent failure path on read/write/CLI input that turns operator mistakes into invisible losses.

**Dependencies.** M0.2 (geth compile-clean), M0.3 (atomicio), M0.4 (`requireNoArgs` helper + Redact), M0.5 (sentinel infrastructure pattern), M0.6 (`validateSignedAgainstRLP`; receipt-revert path shares `sendAction`).

**Exit criteria recap (project-plan §M0.7).**
- Parallel-write stress test using production `FSWriter` produces 1024 files with no clobber.
- Duplicate-pubkey CLI test: exit 2, both indices named.
- Receipt-revert integration test (e2e tag): exit 5; receipt file present.
- Receipt-timeout integration test: exit 5; receipt absent.
- `make e2e-testnet` script updated; running locally against hoodi with new required flags succeeds.
- `--rpc-url` references in build/run either deleted or reject-with-test (exit 2 + operator guidance).
- `UnsignedTx.From` and `BuildConfig.RPCURL` symbols absent (grep clean).

**Phase totals.** 10 issues, 19 points (~9.5 days single-stream). **Risk flagged (project-plan P2)** — largest single phase by issue count.
