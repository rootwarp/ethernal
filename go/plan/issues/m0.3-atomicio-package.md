## Issue M0.3-1 — `atomicio.WriteFile` + sentinels + unit tests

- **Points:** 3
- **Priority:** P0
- **Closes:** FR-P0-B9 prereq (GO-016), supporting GO-011 in M0.7
- **Depends on:** M0.1-7

**Description.** Implement `WriteFile(path, data, perm)` per architecture §15 and §6.5 — `os.CreateTemp` in `filepath.Dir(path)` → write → `f.Sync()` → `f.Close()` → `os.Rename(tmp, path)` → parent-dir `fsync`. Add sentinels `ErrClobber`, `ErrTempCreate`, `ErrSync`, `ErrRename`.

**Implementation notes.**
- File: new `internal/atomicio/atomicio.go`.
- Refuse to clobber: `os.Lstat(path)` returns `nil` (file exists) → return `ErrClobber` before any temp create.
- Parent-dir `fsync` is best-effort: on macOS, the open-then-`Sync` on the dir may be a no-op; document in package doc comment per research/06 §A.
- Deferred cleanup: if any step fails after `os.CreateTemp` succeeded, `os.Remove(tmp.Name())` in a defer so no partial file is left behind.
- Sentinels declared as `errors.New(...)` package-level vars per CONVENTIONS.md and architecture §15.

**Acceptance criteria.**
- [ ] `TestWriteFile_HappyPath`: write 1 MiB random data → file contents equal input.
- [ ] `TestWriteFile_NoClobber`: path already exists → returns `ErrClobber`; original file untouched.
- [ ] `TestWriteFile_TempFailureCleansUp`: simulated temp-create failure leaves no `.tmp` file in dir.
- [ ] `TestWriteFile_PermApplied`: file has the exact `perm` requested (verified via `os.Stat`).
- [ ] `go test -race -count=10 ./internal/atomicio/...` passes.

## Issue M0.3-2 — `atomicio.WriteFileWithSuffix` (RFC3339Nano + sha256[:4] naming)

- **Points:** 3
- **Priority:** P0
- **Closes:** FR-P0-B3 mechanism (GO-011)
- **Depends on:** M0.3-1

**Description.** Implement `WriteFileWithSuffix(dir, prefix, ext, data, perm, now) (finalPath, sha256hex, error)` per architecture §15. Filename scheme `<prefix>-<UTC RFC3339Nano>-<sha256[:4hex]>.<ext>` (research/06 §A). Returns full sha256 hex as second value so caller can tie summary line to artifact bytes.

**Implementation notes.**
- File: same `internal/atomicio/atomicio.go`.
- Use UTC: `now.UTC().Format(time.RFC3339Nano)`.
- sha256: full hex returned to caller; only first 4 hex chars in filename (per architecture §10.2).
- Internal: delegate to `WriteFile` once the final path is computed, so no-clobber semantics inherited.

**Acceptance criteria.**
- [ ] `TestWriteFileWithSuffix_FilenameScheme`: filename matches `^prefix-\d{4}-...-[0-9a-f]{8}\.ext$` regex.
- [ ] `TestWriteFileWithSuffix_Sha256Matches`: returned `sha256hex` equals `sha256(data)` hex.
- [ ] `TestWriteFileWithSuffix_NoClobber`: feeding the same `now` + `data` twice → second call returns `ErrClobber`.
- [ ] `TestWriteFileWithSuffix_HighResUnique`: 100 sequential calls with `time.Now()` produce 100 distinct paths.

## Issue M0.3-3 — Parallel-write stress test (1024 files, no clobber)

- **Points:** 2
- **Priority:** P0
- **Closes:** FR-P0-B3 acceptance (GO-011)
- **Depends on:** M0.3-2

**Description.** Stress test: spawn N goroutines each calling `WriteFileWithSuffix` with shared `dir`, same `prefix`+`ext`, and distinct (or shared) `data`. Run with `N >= 1024` workers/iterations; assert exactly N files exist post-run and no clobber occurred.

**Implementation notes.**
- File: `internal/atomicio/atomicio_stress_test.go` (or part of `atomicio_test.go`).
- Vary the `data` payload across workers to ensure sha256 disambiguation pulls weight when `time.Now()` collides at nanosecond granularity.
- Gate the stress test with `testing.Short()` skip for fast CI lanes; run unconditionally in `make test`.
- Add to `make test-race` so race detection covers the path.

**Acceptance criteria.**
- [ ] `TestWriteFileWithSuffix_ParallelStress_1024` produces 1024 files; `len(os.ReadDir(dir)) == 1024`.
- [ ] Zero returned `ErrClobber` errors in any worker.
- [ ] Test green under `-race -count=10`.
- [ ] Cumulative `make test` runtime increase < 5 s on a modern laptop.
