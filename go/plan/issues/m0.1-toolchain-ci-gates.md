# Phase M0.1 — Toolchain, CI & Lint Gates Foundation

**Objective.** Land the gating infrastructure (toolchain pin, `govulncheck`, `errcheck`, `gofmt`, weekly vuln scan, `-race` lane) before any code change so every subsequent PR is built/tested under the new gates.

**Dependencies.** Prerequisites complete (signed-off PRD + architecture; clean `develop`; `go1.26.4` available locally or via `GOTOOLCHAIN=auto`).

**Exit criteria recap (project-plan §M0.1).**
- `make lint` runs gofmt + vet + staticcheck + errcheck + govulncheck and passes locally.
- CI `lint`, `test-race`, weekly `vuln-scan` jobs green/scheduled.
- `go.mod` shows `toolchain go1.26.4`; `gofmt -l .` empty; `docs/SECURITY.md` published.

**Phase totals.** 7 issues, 13 points (~6.5 days single-stream).

**Acceptance criteria.**
