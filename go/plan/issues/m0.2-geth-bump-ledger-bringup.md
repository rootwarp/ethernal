## Issue M0.2-3 — `LedgerSigner.Sign` cross-check sender + tx fields; `ErrSenderMismatch`

- **Points:** 3
- **Priority:** P0
- **Closes:** FR-P0-D3 (GO-023)
- **Depends on:** M0.2-2

**Description.** After Ledger signs and returns the tx, cross-check the recovered sender against `s.account.Address` and field-compare every returned field (nonce/to/value/data/chainID/maxFee/tip/gasLimit) against the requested tx. Mismatch on any → new sentinel `ErrSenderMismatch`.

**Implementation notes.**
- File: `internal/signer/ledger.go` (`LedgerSigner.Sign` method).

- Field comparison must be done on the parsed transaction, not the raw RLP — use the geth `types.Transaction` accessors.
- New sentinel `var ErrSenderMismatch = errors.New("recovered sender does not match key/account address")` per architecture §15; exit code 3.
- Update `cmd/eth-deposit-tx/exit.go` exit-code map.

**Acceptance criteria.**
