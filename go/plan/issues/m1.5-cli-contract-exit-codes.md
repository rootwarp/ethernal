# Phase M1.5 — CLI Contract & Exit Codes

**Objective.** Close FR-P1-F — every error wrapping, exit-code, and CLI input path is tightened. Lands the `TestExitCodeContract` table that gates every M1+ PR. **M1.5 is sequenced first in single-stream M1 ordering** (per project-plan §Within M1) because `TestExitCodeContract` is the contract every later phase must respect.

**Dependencies.** M0.11, M1.1 (cancellation interacts with F6 ctx propagation).

**Exit criteria recap (project-plan §M1.5).**
- `TestExitCodeContract` green for both binaries; covers every sentinel in architecture §15.
- `--input - --yes` test: prompt from `/dev/tty` when available; reject with `ErrNoTTY` otherwise.
- `errors.Is(err, context.Canceled)` survives `BroadcasterChainID` failure (GO-042 regression).
- `runDepositCLIVerify` SIGINT mid-exec → exit 4.

**Phase totals.** 9 issues, 20 points (~10 days single-stream).
