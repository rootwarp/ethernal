**Discharges:** T-6, T-13, T-14·partial · **the critical path (live tier)** · **→ M6 (headline risk)**

The real-EVM half the Stub cannot reach — and, with the ceremony tier deferred, **now the critical path and
the headline risk burn-down (M6)**. Every live test is `#[ignore]`-gated **and** opens with a
skip-with-notice guard, so a missing `anvil` binary is a green no-op, never a red (D-3). Independent of the

## [E6-1] Anvil harness `tests/common/anvil.rs` (T-1 anvil half)

**Points:** 3 · **Stream:** B · **Depends on:** — · **Discharges:** T-1 (anvil half)

**Description.** An `Anvil` guard mirroring `Stub`'s lifecycle discipline, over the `anvil` binary. Add a
**smoke test** (skip-aware) so the merge is non-vacuous.

**Implementation notes.** `tests/common/anvil.rs` (new, `#[cfg(unix)]`), per architecture §`anvil.rs`:
- `try_spawn(chain_id)` — **skip with an `eprintln!` notice and return `None`** when the `anvil` binary is
  absent (D-3/A-6); `--port 0` + scrape `"Listening on 127.0.0.1:<port>"` (zero bind-close-respawn race);
  a background **stdout drain thread** (foundry #3414 — anvil blocks once the pipe fills); `eth_chainId`
  RPC-poll readiness backstop. Chain-id defaults to `560048` (hoodi, A-3).
- `url`, a **hand-rolled dependency-free JSON-RPC POST** (`rpc`, D-7 — requires only `anvil`, not `cast`;
  reuses the same dependency-free HTTP the `Stub` proves works, `common/mod.rs:188`), `set_balance`
  (`anvil_setBalance`), `set_nonce` (`anvil_setNonce`), and `Drop` (kill + reap).
- `tests/common/mod.rs` (edit): `pub mod anvil;`. The module-level `#![allow(dead_code)]` propagates in, so
  the harness compiles clean until E6-2 consumes it.
- **Smoke test** (`#[ignore]`, skip-aware): `let Some(a) = Anvil::try_spawn(560048) else { return };`
  then assert `rpc("eth_chainId", …)` returns `560048` and `Drop` reaps.

**Acceptance criteria.**
- [x] With `anvil` present: `cargo test --workspace --test 'e2e*' -- --ignored` runs the smoke test green
      (`eth_chainId` round-trips `560048`).
- [x] Without `anvil`: the smoke test is a green skip (prints the notice, no failure).
- [x] `make lint && make test` green (the harness is dead-code-allowed; no live test enters the hermetic tier).

**Out of scope.** The live pipe chain (E6-2); T-13 probes (E6-3); CI wiring (E6-4); adding a `cast` / Rust
EVM dependency.

## [E6-2] Live pipe chain moves 32 ETH against anvil (T-6)

**Points:** 2 · **Stream:** B · **Depends on:** E6-1 · **Discharges:** T-6

**Description.** `tests/e2e_live.rs` (new, `#[ignore]`-gated, skip guard first): start anvil (hoodi
`560048`, ephemeral port), fund the phase-3 sender via `anvil_setBalance`, run
`gen --dry-run | build --input-file - | sign --input - | send --yes --input - --rpc-url <anvil>
--wait-for-receipt`, and assert **(a) a successful receipt AND (b) the deposit-contract address's balance
grew by 32 ETH per deposit.**

**Implementation notes.** Wording is **bound by D-9**: the claim is *"a valid Ethereum tx was accepted by a
real EVM and 32 ETH moved to the deposit-contract address,"* **NOT** *"the deposit contract validated the
deposit"* — bare anvil (`--chain-id 560048`, empty genesis) has no deposit-contract code, so `send` is a
value transfer to a codeless address. The test **and any comment/doc must not over-claim** contract-logic
validation. Read the deposit-contract address from the **built tx's `to` field** (no address committed).
Use `phase3_*()` consts + `PHASE3_KEY` (sender `0x1a642f0E3c3aF545E7AcBD38b07251B3990914F1`); ephemeral
port, not the skill's fixed `8599` (C-2). Skip guard: `let Some(anvil) = Anvil::try_spawn(560048) else {
return };`.

**Acceptance criteria.**
- [x] With `anvil`: `cargo test --workspace --test 'e2e*' -- --ignored` green — successful receipt **and**
      deposit-contract address balance grew 32 ETH per deposit.
- [x] Without `anvil`: green skip (no-op).
- [x] Test/comment wording matches D-9 (valid-tx-accepted + value-moved; no contract-logic claim).
- [x] The live test is **absent** from `make test` (`#[ignore]` + not an `e2e*` binary in the hermetic tier);
      `make lint && make test` green.

**Out of scope.** Deposit-contract-**logic** validation (D-9 — manual/real-network path); T-13 (E6-3); CI
triggers (E7); `run --rpc-url` live (T-17 deferred, D-5).

## [E6-4] `e2e-live.yml` — `workflow_dispatch`-only (T-14·partial, M6)
