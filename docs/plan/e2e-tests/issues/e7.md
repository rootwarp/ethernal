## [E7-1] Makefile two-tier targets + `e2e-live.yml` triggers (T-14)

**Points:** 2 · **Depends on:** E6-2, E6-3, E6-4 · **Discharges:** T-14

**Description.** Wire the hermetic and live tiers as two isolated tiers: the hermetic tier (existing tests +
this stage's new hermetic tests — T-3, T-7/8/19, T-12·recover) runs on every PR inside `make test`; the live
tier (`#[ignore]`d anvil tests) runs only nightly / on release tags / on manual dispatch, never PR-blocking.

**Implementation notes (both edits are required — do not drop either).**
- `Makefile` (edit, D-6): **DROP `--include-ignored` from `e2e-mock`** (behavior-neutral today — nothing
  is `#[ignore]`d yet — and it is what keeps the live tests out of the hermetic gate going forward); **add
  `e2e-live: cargo test --workspace --test 'e2e*' -- --ignored`**.
- `.github/workflows/e2e-live.yml` (edit): **switch the run step to `make e2e-live`** (E6-4 used the inline
  command); **add** the `schedule` (nightly, placeholder `0 7 * * *`) and `push` on `v*.*.*` release-tag
  triggers alongside the existing `workflow_dispatch`. Not PR-blocking; **no** job retries / no
  `continue-on-error` (a nightly failure is a real signal). All actions stay SHA-pinned (`9bec2c2`);
  Foundry stays `version: v1.7.1`.
- `ci.yml` stays **unchanged** — this stage's new hermetic tests (T-3, T-7/8/19, T-12·recover) already run
  transparently inside `make test` (no external toolchain), so the hermetic side of T-14 needs no CI edit.

**Acceptance criteria.**
- [x] `make e2e-live` runs **only** the `#[ignore]`d live tests in the `e2e*` binaries.
- [x] `make e2e-mock` / `make test` run **only** the hermetic tier (no live test); `grep` shows the
      `e2e-mock` target no longer passes `--include-ignored`.
- [x] `e2e-live.yml` triggers on `schedule` + `workflow_dispatch` + `push` `v*.*.*`, and its run step is
      `make e2e-live`.
- [x] `ci.yml` unchanged.
- [ ] first scheduled/dispatched run green (pending remote push).
- [x] `make lint && make test` green.

**Out of scope.** Any `ci.yml` edit; making the live tier PR-blocking; new commands/flags.
