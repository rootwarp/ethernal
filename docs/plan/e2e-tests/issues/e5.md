## [E5-2] Mainnet safety guard + golden + pipe gotcha (T-8)

**Points:** 2 · **Stream:** B · **Depends on:** E5-1 · **Discharges:** T-8

**Description.** Assert the `--i-understand-this-is-mainnet` guard and the mainnet golden, plus the
verify-skill pipe gotcha:
- `gen --network mainnet` **without** the flag → **exit 2**, message names the flag.
- **with** the flag → proceeds and output **byte-matches** `testdata/mainnet/deposit_data-expected.json`.
- `gen` without `--passphrase-env` in a pipe prompts on `/dev/tty` and dies non-TTY with **exit 2** naming the flag.

**Implementation notes.** `tests/common/mod.rs` (edit): add `mainnet_*()` accessors. `tests/gen.rs`
(edit): the guard is safety-critical and has no test today. The exit-2 message must name the flag; the
byte-match reuses the same golden-equality shape as E5-1.

**Acceptance criteria.**
- [ ] `cargo test --test gen` green.
- [ ] Without the flag → exit 2 naming `--i-understand-this-is-mainnet`; with it → byte-match mainnet golden.
- [ ] Pipe without `--passphrase-env` → exit 2 (non-TTY, names the flag).
- [ ] `make lint && make test` green.

**Out of scope.** Any real broadcast (anvil-only; T-8 is `gen`-golden + guard, never a send).
