## [E4-2] Symlink `--output-dir` warning on the recover/stdin path (T-12·recover)

**Points:** 1 · **Depends on:** — · **Discharges:** T-12·recover

**Description.** A symlinked `--output-dir` on the *recover/stdin* path emits the documented warning
(`1736843`). No PTY needed — this is the stdin variant, reachable non-interactively.

**Implementation notes.** Extend `tests/key_e2e.rs` and `tests/account_e2e.rs`, reusing the existing stdin

`recover_load_config_warns_on_symlinked_output_dir` in both `*_cli.rs`; this adds the binary-level
assertion. Assert the warning on stderr; pin whatever the code does (warn + still writes, per `1736843`).

**Acceptance criteria.**
- [x] `cargo test --test key_e2e --test account_e2e` green.
- [x] Symlinked `--output-dir` on the recover path emits the documented stderr warning for both commands.
- [x] `make lint && make test` green.

**Out of scope.** The new-path (ceremony) symlink assertion (T-12·new, deferred); PTY.
