## [E3-1] v3 correctness via `account recover` + `decrypt_v3` round-trip (T-3)

**Points:** 2 · **Depends on:** E2-1 · **Discharges:** T-3

**Description.** `tests/account_e2e.rs` (edit): drive `account recover` with the committed `ABANDON_12`
fixture (piped stdin, empty mnemonic-passphrase, `--passphrase-env`) to produce **Web3 v3** keystores, then
prove v3 correctness through the binary. Validate structurally (`version: 3`, `crypto.cipher = aes-128-ctr`,
scrypt kdf, keccak `mac`, top-level `address`, geth `UTC--…` filename, `0600`) **plus**
`decrypt_v3(json, pass) → secret → derive address == keystore `address` == fixture address` (from
`testdata/eoa/cross-recovery.json`) — proving derivation **and** v3 encrypt self-consistency (D-4).

**Why the `decrypt_v3` round-trip is the point.** The existing `account_recover_keystores_match_fixture`
(`account_e2e.rs:276`) already checks the v3 structure + the top-level `address`, but **never decrypts the
ciphertext** — and `address` is written independent of the ciphertext (`encrypt_v3.rs`), so a v3-**encrypt**
bug passes address-match. `decrypt_v3` (E2-1, the feature-gated test-only reader) closes exactly that gap
and restores parity with the v4 `Loader` round-trip. The result holds regardless of how the keystore was
produced, so it also covers the deferred ceremony write path (byte-identical crypto).

**Implementation notes.** Land beside `account_recover_keystores_match_fixture`, reusing its `ABANDON_12`
const, `run_account_recover` helper, `v3_files()` / `parse_v3_filename` helpers, and `load_fixture()`
(the cross-recovery addresses). `decrypt_v3` comes from E2-1 (activated via the bin's `[dev-dependencies]`
feature line). No `Loader` round-trip (no v4 for v3). No PTY, no new fixture.

**Acceptance criteria.**
- [ ] `cargo test --test account_e2e` green (the new T-3 test + the existing suite).
- [ ] v3 structural asserts pass (version/cipher/kdf/mac/address/filename/`0600`) for each fixture index.
- [ ] `decrypt_v3(json, "password1")` → secret → derived address == keystore `address` == the fixture's
      `address`/`eip55` from `cross-recovery.json`, for every index.
- [ ] `make lint && make test` green.

**Out of scope.** The `account new` ceremony write path and T-4/T-5/T-10/T-11/T-12·new (deferred,
[`deferred.md`](deferred.md)); no in-binary v3 reader.
